# MAPS WITH TEETH — VERIFICATION STANDARD

Every public resource must meet one of the following defensibility tiers:

1. **PRIMARY_STATUTE**: Direct citation to state or federal legislative code, administrative rule, or published court precedent.
2. **GOVERNMENT_PORTAL / 501C3_STANDARDS**: Published official program rules on an active .gov portal or active 501(c)(3) charity website.
3. **DIRECT_AGENCY_INTERVIEW**: Documented conversation with an authorized intake coordinator or program director.

### Prohibitions:
- Never cite blog posts or third-party directory aggregators as primary sources.
- Never use replacement-card administrative rules as authority for substantive identity changes.
- Never assert "zero notification" without analyzing carrier billing mechanics.
