# EDITORIAL & CONTENT MODEL

Content is strictly separated from data and application logic:
- `src/content/articles/`: Formally authored long-form articles.
- `src/content/field-notes/`: Practitioner observations and tactical field notes.
- `src/content/explainers/`: Deep-dive statutory and institutional explainers.
- `src/content/initiative/`: Public governance, mission, and budget disclosures.
