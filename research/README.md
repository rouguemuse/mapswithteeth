# RESEARCH DIRECTORY

This directory houses exploratory research, lead discovery inventories, and background documentation.

> **CRITICAL SECURITY RULE**:  
> `research/` is NOT a security boundary. Never commit survivor PII, private case records, credentials, or confidential partner communications. See [`docs/standards/RESEARCH_SECURITY.md`](../docs/standards/RESEARCH_SECURITY.md).

## Subdirectories
- `resources/master-ledger/`: Canonical Master Resource Reconciliation Ledger tracking lead states and research history.
- `resources/leads/`: Discovery dumps and candidate program notes pending verification.
- `states/`: Multi-state statutory research notes and comparative policy memos.
- `systems/`: Institutional workflow models (housing authorities, court clerk dockets, utility commissions).
